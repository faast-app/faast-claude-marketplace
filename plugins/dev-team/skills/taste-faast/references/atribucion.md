# Atribucion

`taste-faast` es una adaptacion al contexto FaaST (producto fintech, propuestas de diseño,
sistema visual heredado de la libreria `@faast-app`) de **tasteskill 2.5.1**
(`design-taste-frontend`) de Leonxlnx.

- Fuente: https://github.com/Leonxlnx/taste-skill (commit `f6b76575f949707b4e3c37cd86cb44b0b98643e8`, revisado 2026-11-10)
- Licencia: MIT, Copyright (c) 2026 Leonxlnx

Se tomaron y reescribieron en español sus ideas rectoras (un sistema, una seccion por
pantalla, bordes iguales, todo dibuja, sin leyendas, texto llano, repartir en vez de elegir,
puerta final en navegador). No se copio su kit (CSS, scripts, efectos, fotos): el sistema
visual aqui es la libreria FaaST. Para sitios publicos se puede instalar la skill original
(`npx skills add Leonxlnx/taste-skill`) y usarla como indica `SKILL.md`.
