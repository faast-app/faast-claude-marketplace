# faast-brain

El conocimiento del negocio de FAAST, destilado y enlazado: productos, clientes, procesos,
integraciones, reglas, vocabulario y decisiones. Lo mantiene la Mesa de Servicios (agente
curador) y lo lee antes de preguntarle algo a un cliente, para preguntar poco y bien.

- Abrelo como vault en **Obsidian** para ver el mapa (graph view) y los `[[enlaces]]`.
- Esquema y reglas para agentes: [CLAUDE.md](CLAUDE.md). Portada: [index.md](index.md).
- Operaciones: `/mesa-servicios:brain init | ingest {ID} | query "…" | lint`.

**Nunca** contiene secretos ni datos personales de personas. Lenguaje de negocio, sin codigo.
